# andres-jaramillo · portfolio

Personal site of Andrés Jaramillo, AI Engineer. Spanish at `/`, English at `/en/`.

**Stack:** Astro (static output) · Tailwind CSS 4 · vanilla TypeScript for the hero node graph · Vercel Hobby.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

All copy lives in `src/i18n/es.ts` and `src/i18n/en.ts`. See `CLAUDE.md` for structure and design rules.
